# 封面模块（自带 · 提示词规范 v0.4）

> **解决的问题**：每个攻略都要有好看的封面，而且**要“温暖人心”** —— 让人一看就觉得“这趟值得去”。
> **本模块的结论**：**走 AI 生图**；风格锁定 **中国风审美 × 胶片做旧（富士系）**；**画面内容跟出行日期走**（该时节该景点的真实样子）。
> **为什么不用图库 / 不用 Bing 抓图** → 见 §13（实测留档，别重走）。

## 0. 本轮方向调整（v0.3 → v0.4 · 留痕）

| 旧口径 | 新口径 | 为什么改 |
|---|---|---|
| **不要生写实照片**（“写实容易像假照片”），走**剪影 / 扁平插画** | ✅ **要“胶片写实照片感”** —— 但有严格约束 | 用户要求“让人**联想到真实景点照片**”。剪影虽然稳，但**没有温度**——它像图标，不像记忆 |
| 色调 = “与封面主色一致” | ✅ **五种中国风色彩母题**（有出处可依） | “跟主色一致”太粗，出不来中国味 |
| 风格 = “扁平插画 / 极简矢量” | ✅ **中国风（内容层）× 胶片做旧（呈现层）** | 把“画什么”和“怎么拍”分开，两个维度各管各的 |
| 与日期无关 | ✅ **日期 → 时节 → 实景**（新增） | 10 月的重庆和 7 月的重庆不是一回事；**对应时节的画面才有温度** |

> **“剪影 / 插画”降为降级档**（风格 B）—— 不是删除，是**从主选降为备选**。写实生图质量不稳时退到它。

## 1. 方案总表

| 层 | 做法 | 门槛 | 相关性 | 何时用 |
|---|---|---|---|---|
| **L0 · 保底** | **CSS 生成**（城市名大字 + 主色渐变 + 几何构成） | **零依赖** | 不相关，但可控 | **所有失败的落点，永远可用** |
| **L1 · 主方案** | **AI 生图** → base64 内联 | 宿主有生图能力 | ★★★★ | **默认走这条** |
| **L2 · 增强** | **用户投喂实拍** | 用户给图 | ★★★★★ | 用户主动给了照片 |

**L1 内部有两档风格**：

| 档 | 风格 | 说明 |
|---|---|---|
| **风格 A（主）** | **胶片做旧写实**：中国风构图 + 富士胶片质感 | 本人本模块的主体，见 §2~§10 |
| **风格 B（退）** | 剪影 / 写意插画 | 写实不稳、出现畸变 / 假感时的**退路** |

**判定顺序**：用户给照片 → **L2**；否则 → **L1（先 A 后 B）**；生图不可用 / 失败 → **L0 CSS**。

## 2. 核心设计：两层分工

这是本模块最重要的一个设计决定 —— **把中国风和胶片感拆成两个维度**，而不是混着写：

| 维度 | 层 | 负责什么 | 内容 |
|---|---|---|---|
| **中国风** | **内容层** | **拍什么** | 主体选择、构图法（框景/对称/留白/借景）、色彩母题、光线气质 |
| **胶片做旧** | **呈现层** | **怎么拍** | 影调压缩、颗粒、高光晕、色偏、暗角 |

**为什么这样拆**：两者本来是不同性质的东西 —— 中国风是**美学体系**，胶片是**成像工艺**。混在一起写 prompt 会互相打架（比如“高饱和 Velvia”和“低饱和中国风”直接冲突）；拆开后**各管一层，冲突就消失了**。

### 2.1 为什么“中国风 + 做旧”这个组合成立（不只是审美偏好）

三条理由，第三条最关键：

1. **色彩同向**：中国风要“低饱和、素雅、温润、不艳不炸”；做旧胶片要“褪色、影调压缩”。**两套体系都往“降低饱和”走，天然兼容。**
2. **光线同向**：中国风讲“**光而不耀**”，偏爱散射光（阴雨雾天反而是黄金时间）；复古胶片的柔和高光过渡也要求避免硬光。**都拒绝中午的硬直射光。**
3. ⭐ **做旧工艺是“掩盖 AI 写实破绽”的最佳手段** ——
   > 现代数码的问题是“太干净、太锐、太完美”，而 AI 写实的破绽恰恰也在“太干净、太锐、太完美”上。
   >
   > **胶片颗粒、高光晕、轻微偏色、暗角、边角柔化 —— 这些“不完美”正好把“AI 感”转化为“胶片感”。**
   >
   > 换句话说：**不靠提高精度去逼近真实照片，而靠加入合理的工艺瑕疵，让画面被感知为“一张真的拍过的照片”。**

   > 📖 **心理学依据（取证）**："Perfect color accuracy looks like a document. Slightly off color looks like a memory."
   > 完美还原像**档案**，微微偏色才像**记忆**。胶片的“不完美”不是缺陷，它是大脑用来判定“这是真实经历的影像”的信号 —— 因为它给观者自己的记忆留了填补空间。
   > 来源：*Why Film Photos Feel More Real Than Digital*（rollbooth.com）

## 3. 提示词规范

### 3.1 七段骨架

```
[① 时节与光线] + [② 主体地标] + [③ 中国风构图] + [④ 色彩母题] + [⑤ 胶片做旧质感] + [⑥ 画幅与留白] + [⑦ 负面约束]
```

**顺序有意义**：先说“**什么时候拍的**”（时节决定光线与氛围），再说“**拍什么**”（主体），最后说“**怎么拍**”（构图 / 色调 / 工艺）。这个顺序符合摄影的叙述逻辑，实测比乱序稳定。

### 3.2 各要素写法

| # | 要素 | 怎么填 | 示例 |
|---|---|---|---|
| ① | **时节与光线** | 由**出行日期推导**（§6）；写**季节 + 物候 + 光线** | `early autumn night, mist over the river, soft diffused light` |
| ② | **主体地标** | 1~2 个当地地标，**保持可辨认**（不要抽象化） | `Hongyadong stilt-house complex on the Jialing riverbank` |
| ③ | **中国风构图** | 四法选一（§4.2） | `framed view, extensive negative space in the upper third` |
| ④ | **色彩母题** | 五选一（§4.1） | `muted celadon-green and ink-grey palette with a single restrained vermilion accent` |
| ⑤ | **胶片做旧质感** | 富士模拟 + 做旧四要素（§5） | `Fujifilm Classic Chrome simulation, low saturation, lifted blacks, fine film grain, subtle halation` |
| ⑥ | **画幅与留白** | **16:9** + 文字安全区 | `16:9 horizontal, clean negative space in the upper third` |
| ⑦ | **负面约束** | 见 §8 | `no text, no watermark, no faces` |

### 3.3 完整模板（可直接复制）

**英文版（推荐，生图模型对英文更稳）**：

```
Film photograph of {landmark} in {city}, {season and time of day}, {seasonal elements},
{Chinese aesthetic composition}, {color motif} palette, {lighting},
Fujifilm Classic Chrome film simulation, low saturation, lifted blacks,
soft highlight roll-off, fine film grain, subtle halation around light sources,
gentle vignette, slightly imperfect focus at the frame edges,
16:9 horizontal, clean negative space in the upper third for typography,
no text, no letters, no watermark, no logo, no signage, no faces, no hands,
no distorted architecture, no oversaturated colors, no HDR look
```

**中文版（宿主生图更吃中文时用）**：

```
{city} {landmark} 的胶片摄影，{季节与时段}，{季节物候细节}，
{中国风构图}，{色彩母题}色调，{光线描述}，
富士 Classic Chrome 胶片模拟，低饱和度，暗部抬起，高光柔和过渡，
细腻胶片颗粒，光源周围轻微光晕，轻微暗角，边角焦点略虚，
16:9 横构图，上方三分之一留出干净文字区，
不要文字、不要水印、不要标志、不要招牌、不要人脸、不要手、不要建筑畸变、不要过饱和、不要 HDR 感
```

## 4. 中国风：内容层

### 4.1 五种色彩母题（选一，不要混）

| 母题 | 取色与做法 | 适合 |
|---|---|---|
| **青绿山水** | 青绿为主、蓝绿渐变、**少量暖色点缀**；冷而不寒、雅而不俗（取自《千里江山图》） | 山水、江景、湿润地区、春夏 |
| **朱红宫墙** | 朱红 + 青灰瓦 + 一小片天。⚠️ **红的饱和度要控住：太艳则俗、太暗则闷** | 古建、宫殿、城门、庙宇 |
| **水墨黛青** | 墨分五色（焦浓重淡清）、低饱和偏青灰；远景加**空气透视**（远山偏蓝） | 雾、雨、山、枯枝、冬 |
| **暖黄灯火** | 暖黄 + 轻微褪色，“围炉夜话”感；白平衡偏暖 | 夜市、老街、室内、冬夜 |
| **素白宣纸** | 宣纸白 + 淡彩，**极高留白** | 雪、梅、江南、清晨 |

> **总原则**：**避开高饱和大红大紫**。中国风的底色是**青、灰、白、黛、墨、赭石、浅黄**这一类“低饱和传统色”。

### 4.2 构图四法（选一）

| 法 | 做法 | 适合 |
|---|---|---|
| **框景** | 用窗、门洞、回廊、拱门当框架，拍框里的景 | 有窗棂/门洞可借的场景 |
| **对称** | 古建、走廊、桥、庭院居中对称 | 建筑、宫殿、桥 |
| **三分 + 留白** | **天占 2/3、地占 1/3** —— 意境最足，**且天然就是文字安全区** | 山水、江景、夜空 |
| **借景** | 前景放竹叶、树枝、灯笼、飞檐，制造纵深 | 大部分场景可加 |

**要保留的“骨架元素”**（中国风的线条来源）：飞檐、瓦片、窗棂、栏杆、桥、树枝 —— 这些是“国风骨架”，比大面积色块有效得多。

### 4.3 光线：**光而不耀**

| 要 | 不要 |
|---|---|
| 散漫光、晨昏斜射光、薄雾、雨后 | 正午硬直射光、硬边阴影 |
| 高光柔和晕开（与胶片 halation 天然契合） | 高光死白溢出 |

> **反常识但有据**：**阴天、雨天、雾天**是中国风摄影的黄金时间，不是“烂天气”。

## 5. 胶片做旧：呈现层

### 5.1 富士胶片模拟怎么选（依据富士官方对各模拟的定义）

| 模拟 | 官方特征 | 判断 |
|---|---|---|
| **Classic Chrome** | 低饱和、阴影抬起、色调过渡略硬、**重现 20 世纪纪实杂志效果** | ✅ **主推** —— 最贴中国风的“温润克制” |
| **Nostalgic Neg.** | **高光偏琥珀、阴影浓厚、色彩略褪**，如同**老相册照片** | ✅ **做旧首选** —— 最贴“做旧照片” |
| **PRO Neg. Std** | 柔和色调层次、中性 | ✅ 最柔档，题材吃不准时用 |
| **ETERNA** | 饱和度降到最低、高光暗位柔和过渡、**电影感** | ✅ 电影感档（适合雨雾山水） |
| **Classic Neg.** | 高对比、**琥珀色阴影 + 微青高光**（色彩分离） | 🟡 可用，但对比偏硬，中国风场景慎用 |
| **Velvia** | **超高饱和、高反差**（风景专用） | ❌ **排除** —— 与中国风“低饱和”直接冲突 |
| **ACROS** | 黑白、超细颗粒、阴影细节丰富 | 🟡 特例：水墨题材可用 |
| **SEPIA** | 怀旧棕褐 | 🟡 慎用（容易土） |

### 5.2 做旧四要素（写进 prompt 的那个“工艺层”）

| # | 要素 | 写什么 | 效果 |
|---|---|---|---|
| 1 | **影调压缩** | `lifted blacks` / `soft highlight roll-off` | **黑不死黑（抬到深灰）、高光柔化不溢出** —— 老照片最容易被识别的特征 |
| 2 | **颗粒** | `fine film grain` | ⚠️ 要**胶片颗粒**，不是数字噪点；颗粒在**中灰与暗部更明显** |
| 3 | **镜头性格** | `subtle halation` / `gentle vignette` / `slightly imperfect focus at frame edges` | 高光柔晕 + 暗角 + 边角柔化 |
| 4 | **色偏** | 高光偏**奶油/象牙**，阴影偏**深蓝/梅子**；整体轻微暖调 | **“轻微偏色”是真实感的来源**，不是缺陷（§2.1） |

### 5.3 一句话记住

> **不是“拍得更好”，是“拍得像真的拍过”。**
> 数字的极致干净 = 假；**合理的工艺瑕疵 = 真**。

## 6. 日期 → 时节 → 实景（**本模块的灵魂**）

> **用户要求**：“抓取到用户对话中日期 / 日期推测信息，对应日期对应景点在该时间的**较为真实的风景**，这样比较能温暖人心。”

### 6.1 三步流程

```
① 取日期
     明确日期（“10 月 1 日出发”）> 相对日期（“国庆”“暑假”“寒假”“下周”）
     > 推测（没说 → 按当前所在季节，或最近的长假）
     ⚠️ 推测的必须在生成时说明“按 X 季节假设”
      ↓
② 检索该城市该时段的「地标实景事实」（P14：这是事实层，要检索，不许编）
     · 天气与季节感（雨？雾？雪？闷热？）
     · 植被状态（新绿 / 浓荫 / 银杏黄 / 红枫 / 枯枝）
     · 水域与雪况（江水颜色、是否封冻、积雪）
     · 昼长与光线（日出日落时间 → 是否有蓝调时刻）
     · 人流氛围（假期 vs 平日）
      ↓
③ 译成 prompt 的画面要素（填进 §3.1 的 ① 时节与光线）
```

**为什么必须检索而不是套模板**：同一座城市，10 月和 7 月的画面差得很远；而**用户要的正是“那几天它真实的样子”**。套模板会写出“放之四季皆可”的假图 —— 那恰恰失去温度。

### 6.2 节气审美锚点（快速起点，检索优先于本表）

| 时段 | 物候与画面 | 可用母题 |
|---|---|---|
| **早春**（2 月下–3 月） | 梅、早樱、新绿初生、薄雾、天色转亮 | 素白宣纸 / 青绿山水 |
| **清明–谷雨**（4 月） | **烟雨**、湿石阶、柳、油菜花 | 水墨黛青 / 青绿山水 |
| **初夏**（5–6 月） | 浓荫、丰水期、江面蒸腾 | 青绿山水 |
| **盛夏**（7–8 月） | 烈日、强对流、雷雨后通透、夜市最旺 | 暖黄灯火（夜） |
| **初秋**（9–10 月） | **天高气爽**、桂香、江水转清、晨雾 | 青绿山水 / 水墨黛青 |
| **深秋**（11 月） | **银杏黄、红枫**、落叶、斜阳长影 | 朱红宫墙 / 暖黄灯火 |
| **初冬**（12 月） | 枯枝、薄霜、天色灰蓝、炊烟感 | 水墨黛青 |
| **隆冬**（1–2 月） | **雪、冰、封江**、昼短、低角度金光 | 素白宣纸 + 暖黄灯火（冷暖对照） |

**南北差异要记住**：同样的月份，哈尔滨是冰天雪地，广州还在穿短袖、三角梅正开。**检索目标城市的实际数据，不要按“季节刻板印象”下笔。**

### 6.3 两个完整示例

**例 1 · 重庆 · 10 月上旬（4 天 2 人）**

```
① 日期：10 月上旬 → 初秋
② 检索到的实景事实：均温 20~26℃、多夜雨、江面易起薄雾；
   黄葛树常绿不落叶；国庆假期人流大
③ 译成画面：
   early autumn night, light mist rising from the Jialing river, wet stone pavement,
   a few warm-lit windows among the stilt houses,
   framed view across the water, extensive negative space in the upper third,
   muted celadon-green and ink-grey palette with restrained vermilion lantern accents,
   Fujifilm Classic Chrome, low saturation, lifted blacks, fine grain, subtle halation around lanterns
```

**例 2 · 哈尔滨 · 1 月（3 天 2 人）**

```
① 日期：1 月 → 隆冬
② 检索到的实景事实：均温 -18℃ 上下、松花江封冻、积雪覆盖；
   昼短（约 8:30 日出 / 16:30 日落）→ 有低角度金光与长蓝调时段
③ 译成画面：
   deep winter dusk, snow-covered St. Sophia Cathedral, frozen river in the distance,
   snowfall in still air, warm yellow window glow against cold blue snow,
   symmetrical composition, extensive negative space in the upper third,
   ivory white and ink-blue palette with warm amber accents,
   Fujifilm Nostalgic Neg., faded colors, lifted blacks, fine grain, gentle vignette
```

### 6.4 硬规则

1. **能拿到明确日期就一定用真实日期**，不要“随手选个好看季节”。
2. 日期靠推测时，**必须在交付说明里讲清是按什么假设**（“按初秋假设，若实际在冬天告诉我，我重生成封面”）。
3. **画面要素必须和该时节自洽** —— 别在 1 月的哈尔滨图上出现绿叶，别在 7 月的重庆图上出现雾凇。
4. **不检索就不写具体物候** —— 可以只写到“季节 + 光线”这一层，但**不许编造细节**（P14）。

## 7. 三种场景模板（按题材直接套）

| 场景 | 适用 | 关键提示词片段 |
|---|---|---|
| **A · 夜色灯火** | 洪崖洞、外滩、夜市 | `night, warm-lit windows, reflections on water, halation around light sources, lifted blacks, warm amber against deep indigo` |
| **B · 白日古建** | 故宫、寺庙、古镇 | `daylight, symmetrical composition, vermilion walls and grey tiles, restrained red saturation, long soft shadows, Classic Chrome` |
| **C · 山水雾霭** | 西湖、漓江、黄山 | `mist, layered mountains with atmospheric perspective, extensive negative space, celadon-green and ink-grey, ETERNA film simulation, lowest saturation` |

## 8. 负面约束清单（每条都有理由）

| 写什么 | 为什么 |
|---|---|
| `no text, no letters, no watermark, no logo, no signage` | 生图文字必出乱码；**封面还要压自己的标题** |
| `no faces, no hands` | 人脸与手是 AI 最易崩的部位；**顺手避开肖像权** |
| `no distorted architecture` | 地标一旦变形，“一眼认出”就废了 |
| `no oversaturated colors, no HDR look` | 高饱和 + HDR 是“数字假感”的主要来源，与中国风/胶片双重冲突 |
| `no plastic skin, no AI-looking gloss` | 直指“AI 味”本身 |
| `no modern signage, no billboards` | 现代招牌会破坏中国风的年代感 |

## 9. 合规边界：**能写工艺，不能写人**

这条很容易搞混，单独说清：

| 写 法 | 判定 |
|---|---|
| `Fujifilm Classic Chrome` / `Pro 400H` / `Superia` | ✅ **可以** —— 这是**胶片型号 / 工艺参数**，描述的是**材料**，不是模仿某个人 |
| `shot on 35mm film, lifted blacks, film grain` | ✅ 可以 —— 纯技术语汇 |
| `in the style of <在世摄影师>` | ❌ **不可以** —— 这是模仿**创作者**的风格 |
| 真实人物面孔 / 商标 / 赛事标志 | ❌ 不可以 |
| `source_note` 写“AI 生成” | ✅ **必须** —— 如实标注，不假装实拍 |

> **一句话**：**描述“用了什么胶片”没问题，声明“模仿谁的风格”有问题。**

## 10. 留白：两种留白都是刚需

| 类型 | 作用 | 落法 |
|---|---|---|
| **美学留白** | 中国风的“计白当黑”，给画面呼吸感 | 三分法（天 2/3）、大面空白、雾气遮隐 |
| **功能留白** | 封面要压主标题 + 副标题 | **上 1/3 或下 1/3 必须干净** |

**好消息**：这两者可以重合 —— **中国风的“天占 2/3”构图本来就是一个天然文字区**。所以推荐**默认用“上 1/3 留白”**，一次满足两个需求。

## 11. 降级链（**L0 永远可用**）

```
用户给了照片？ ── 是 → L2 用实拍（压到 ≤500 KB → base64 内联）
      │
      否 → L1 AI 生图
             ├─ 风格 A：胶片做旧写实（§2~§10 全套）→ 检查通过 → 用
             └─ 风格 A 不合格（畸变 / 假感 / 糊 / 文字乱码）
                   └→ 风格 B：剪影 / 写意插画（原方案，稳）
                         └→ 仍不可用
                               └→ L0 CSS 生成封面（零依赖，必然可用）
```

**判“风格 A 不合格”的检查点**：① 地标可辨认吗？② 有建筑畸变吗？③ 有乱码文字吗？④ 有糊掉的人脸/手吗？⑤ 整体像“AI 图”还是像“照片”？

---

## 12. 落地硬规则

1. **禁止外链图片** —— 一律 base64 内联（外链会破坏“双击即开”，转发后大概率挂）。
2. **体积预算**：单 HTML 总文件 ≤ 2 MB（**封面图建议 ≤ 500 KB**）。
3. **绝不允许空封面** —— 任何失败都**静默落到 L0 CSS**，不报错、不留空白。
4. `source_note` **必须写**：`AI 生成` / `用户提供`。
5. **封面文字内容**：主标题（城市 + 一句话主题）、副标题（天数 / 日期 / 人数）、生成日期（小字）。
6. **主色**：由城市气质 + **该时节色彩母题**共同推导（不是随便取色）。

## 13. 被否决的两条路线（实测留档 · 别重走）

### 13.1 Bing 图片搜索抓取 —— **否决：问题在版权，不在路径**

实测：图**能下**（499 KB ~ 1.1 MB / 0.3 ~ 0.6 s），流程本身没有障碍。

**但抓到的不是“公共图”，而是商业图库的正版图**：

```
前 10 条结果分布：699pic.com（摄图网）x9 · nipic.com（昵图网）x1
标题原文：「重庆洪崖洞夜景高清图片下载-正版图片500926948-摄图网」
```

→ **这是付费图库的作品被第三方转发**。下下来自己看看没问题，**但放进要分享出去的网页里就是侵权**。
**问题不在“能不能抓到”，而在“抓到的能不能用”。**

### 13.2 公共图库 CDN 直链（Pexels / Unsplash / Pixabay）—— **否决：路径依赖 + 参数坑**

**可达性实测（中国大陆网络环境，逐项实测）**：

| 图源 | 免 Key 搜索 | 免 Key 直链 | 大陆可达 | 结论 |
|---|---|---|---|---|
| Pexels | ⚠️ 搜索页 403，**读页可拿 photo id** | ✅ CDN 200 | ✅ | 能走，**但是“读页面拿 id”的路径依赖** |
| Unsplash | ❌ 站内接口 401 | ✅ CDN 200 | ✅ | 要搜索就得有 Key |
| Pixabay | ❌ 搜索页 403 | ✅ CDN 200（最快 0.5s） | ✅ | 搜索受限 |
| Wikimedia Commons | ✅ 有 API | ✅ | ❌ **超时不可达** | 不可用 —— **授权最干净的一家，恰恰访问不了** |
| Openverse（聚合 8 亿条） | ✅ 免 Key | — | ❌ 超时 | 不可用 |
| Lorem Picsum | ✅ 免 Key | ✅ | ✅ | 图与目的地**无关**，做不了封面 |

**参数坑（实测，Pexels id `25338517`）**：

| 参数 | 体积 | 耗时 | 可否内联 |
|---|---|---|---|
| 无参数（原图） | **4189 KB** | **58.7 s** | ❌ |
| `?auto=compress&cs=tinysrgb&w=1600` | **725 KB** | 6.9 s | ✅ 唯一可用档 |
| `w=1200` / `w=1600&h=900` | — | — | ❌ 503（限流） |

→ 三个叠加的问题：**① 靠“读页面拿 id”是路径依赖；② 参数写错就是 4 MB / 近 1 分钟；③ 偶发 503。**
**“能走通”不等于“该走”。** 既然 AI 生图能同时做到**免 key + 免路径风险 + 无版权问题**，就没有理由再选它。

> **顺带记住一个反差**：Wikimedia Commons 是“公共图源”里**授权最干净、API 最友好**的一家，**但它在国区访问不了**。
> **“最正的方案”不一定是最可用的方案 —— 可达性本身是硬约束。**
