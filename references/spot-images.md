## 1. 一句话

**每张景点卡顶部放一张"游客站在那里真的会看到的"实景图，风格与封面同源（中国风 × 胶片做旧）。**

### 为什么是实景图，不是插画

1. **它是卡片的视觉锚点。** 读者的视线先落在图上，再往下读标题——顺序不能倒过来（见 `design-system.md` §4 第 6 条）。图不对，后面写得多好都是白写。
2. **它替读者做"值不值得去"的第一轮判断。** 一张好图等于提前把"这地方长什么样"交底。
3. **线性抽象图已被否决。** 上一版用几何 SVG 意象图（圆顶山形），能表意但**辨识度为零** —— 桂林的峰林、溶洞、梯田在几何化之后长得差不多，读者分不出这是哪儿。**凡是"可以抽象成一样的"的图，就等于没有图。**

## 2. 规格

| 项 | 值 | 理由 |
|---|---|---|
| 生成尺寸 | **1536×1024**（3:2 横构图） | 生图端可用的最大横画幅；构图余量足够 |
| 构图要求 | **主体集中在画面中央 60% 高度内**，上下留可裁区（天空 / 水面 / 地面） | 卡片显示区是超宽扁条，上下一定会被裁掉 |
| 交付尺寸 | 裁中间条 → **缩到宽 1200px** | 桌面显示宽约 760px，1200 够 1.5× 清晰度；再宽只是白涨体积 |
| 格式 | **JPEG，quality ≈ 78** | 实景照片用 JPEG；PNG 会让 base64 体积翻 3 倍 |
| 内联 | **base64 直接写进 `<img src>`** | 交付物必须是单文件、双击即开、图片不外链 |
| 单张体积上限 | **≤ 160 KB**（base64 后） | 超过就降 quality 或降宽度，不要砍张数 |
| 全页预算 | 封面 ≤ 400 KB ＋ 景点图 ≤ 2.4 MB | 整份 HTML 控制在 **3 MB 以内**仍算轻 |
| 一张卡一张图 | 是 | 同一景点不重复生图 |
| 「可跳」档的卡 | **不给图** | 视觉锚点也要讲稀缺：不推荐的地方不占版面 |

## 3. 提示词

复用 `cover-image.md` §3 的**七段骨架**，只改两处：**画幅段**（改成 3:2 + 中央构图）与**去掉"留文字区"要求**（图下方才是文字）。

```
Film photograph of {画面主体} in {城市}, {季节与时段}, {物候或天气细节},
{中国风构图法}, {色彩母题} palette, {光线},
Fujifilm Classic Chrome film simulation, low saturation, lifted blacks,
soft highlight roll-off, fine film grain, subtle halation around light sources,
gentle vignette, slightly imperfect focus at the frame edges,
3:2 horizontal, main subject centered within the middle 60% of the frame height,
sky and ground at top and bottom are simple and uncluttered (safe to crop),
no text, no letters, no watermark, no logo, no signage, no faces, no hands,
no distorted architecture, no oversaturated colors, no HDR look,
no illustration, no cartoon, no vector art, no flat geometric shapes
```

**末行三条负面约束（`no illustration / cartoon / vector art / flat geometric shapes`）是这张图专属的**——不写，模型很容易给"扁平插画风"，而那正是我们要替代掉的东西。

> 品种与"能写工艺不能写人"等合规边界，与封面模块同一套规则，见 `cover-image.md` §9。**景点人多是常态，但不得出现可辨认的人脸。**

## 4. 画面判据：这个景点拍什么

**判据只有一句：游客站在那里，眼睛看到的是什么。**

填提示词的 `{画面主体}` 时**按下面的字典查**，不要临时拍脑袋：

| 景点类型 | `{画面主体}` 写什么 |
|---|---|
| 江 / 河 / 竹筏 / 漂流 / 二十元背景 | 竹筏漂在江面 + 远处峰林层叠（`bamboo raft on the river with karst peak forest receding into haze`） |
| 峰林 / 山景 / 观景台 | 成片峰林起伏 + 云雾带（`karst peak ranges with mist bands between them`） |
| 溶洞 | 洞内钟乳石 + 彩灯投光（`stalactites inside the cave, colored light wash`） |
| 古镇 / 老街 / 步行街 | 青石板巷 + 两侧老屋屋檐（`stone-paved lane flanked by old tiled roofs`） |
| 梯田 / 田园 / 骑行道 | 层层梯田曲线 + 农舍（`terraced fields in curving layers with a farmhouse`） |
| 湖 / 公园 / 夜景 | 湖面倒影 + 岸边灯火（`lake reflection with lantern-lit shore`） |
| 集市 / 夜市 / 小吃街 | 灯笼与摊位 + 夜色暖光（`lantern-lit food stalls at night`） |
| 演出 / 实景秀 | 舞台光效 + 观众席轮廓（`stage lighting with audience silhouette`，**不得有脸**） |

### 硬约束

1. **禁止用"景点名里含哪个字的"关键词启发式**（曾把「漓江竹筏·杨堤→**兴坪**段」判成古镇，因为名字里有"兴坪"）。**必须查表；表里没有，才按"站在那里看到什么"现判，并把新条目补进表。**
2. **名实必须对得上。** 竹筏图不许配古镇、溶洞图不许配山景——这是**内容错误**，不是审美问题。
3. 判据与旧版 SVG 意象图的映射（`sc-a` 峰林江面 / `sc-b` 溶洞 / `sc-c` 古镇 / `sc-d` 田园 / `sc-e` 夜市）**同源**，只是从"画一个符号"升级成"拍一张照片"。

## 5. 裁切与压缩

处理顺序固定，不要颠倒：

1. **裁**：从 1536×1024 里取**中央横条**（建议 1536×620，约 2.5:1）。
2. **缩**：宽度缩到 **1200px**（高度约 484）。
3. **压**：存 **JPEG quality 78**。
4. **查**：单张超过 160 KB → 先把 quality 降到 70，再不行降到宽 1000。**不要靠减张数解决体积。**
5. **内联**：`<img src="data:image/jpeg;base64,{…}" alt="{景点名}">`。

**为什么先裁后缩**：先缩会把要保留的细节一起缩掉，再裁就糊了。裁切决定构图，缩放决定清晰度 —— 先构图后清晰度。

## 6. 降级链

**生图是主路径，但不是前置条件。** 三层，自上而下：

| 档 | 触发条件 | 做法 |
|---|---|---|
| **L1 · AI 生成**（默认） | 环境有生图能力 | 按 §3 生成 → §5 处理 → 内联 |
| **L2 · 用户实拍** | 用户自己提供照片 | 按 §5 裁压缩后内联；**不为凑图而不用用户照片** |
| **L0 · SVG 意象图**（保底） | 环境**没有**生图能力 | 改用 `../assets/template.html` 里内置的 `<symbol id="sc-a…e">`，即 `<svg role="img" aria-label="{景点名}示意图"><use href="#sc-c"/></svg>` |

**为什么保底档必须留着**：这份 skill 要在别人的环境里跑，别人的环境未必有生图能力。**硬依赖生图 = 换个环境就跑不起来**，这是不可接受的分发缺陷。

**L0 的图是"有总比没有好"，不是"可以接受"。** 凡是能生图的场合，一律用 L1。

---

## 7. 硬规则

1. **画面必须能让读者认出"这是哪儿"** —— 认不出就是废图，重生成。
2. **一张卡一张图，不许几张卡共用一张。**
3. **体积守在上限内**：单张 ≤160 KB，整页 ≤3 MB（含封面）。
4. **不许外链**：任何情况下图片都必须是 base64 内联。
5. **不许出现文字/招牌/水印/可辨认人脸**（合规，同 `cover-image.md` §9）。
6. **风格与封面同源**，但**不要比封面更"重"** —— 封面是第一眼，景点图是沿途的风景，后者在个性上应当收敛。
7. 「可跳」档不给图。

## 8. 与封面模块的分工

| | 封面（`cover-image.md`） | 景点图（本文件） |
|---|---|---|
| 数量 | 1 张 | 每张景点卡 1 张（可跳档除外） |
| 作用 | **第一眼**：让人想点进来 | **沿途**：让人相信这不是泛泛而谈 |
| 画幅 | 16:9 + **上方留文字区** | 3:2 → 裁中央横条，**不留文字区** |
| 构图 | 讲究留白与"框景" | 主体居中，上下留可裁区 |
| 体积 | ≤400 KB | ≤160 KB/张 |
| 降级 | L0 CSS 渐变保底 | L0 SVG 意象图保底 |

**两者共用同一套风格底座**：中国风（管"拍什么"）× 胶片做旧（管"怎么拍"）、同一色彩母题库、同一光线要求。细节见 `cover-image.md` §4 / §5。

## 9. 分类图（必读指南用）

必读指南的每个分组顶部有一张**分类图**。它回答的不是"这个景点长什么样"，而是"**这一类长什么样**"。

| 项 | 值 | 理由 |
|---|---|---|
| 数量 | **每个非空分组 1 张**（最多 5 张：景点 / 美食 / 住宿 / 交通 / 打卡） | 空组不渲染，连图一起省 |
| 生成尺寸 | **1536×1024**（同景点图） | 复用同一套生成参数 |
| 交付尺寸 | 裁**超宽横条**（1536×380，约 4:1）→ 缩到宽 **1000px** → JPEG **q78** | 显示区仅 130px 高、约 480px 宽，1000px 已够 2× |
| 单张上限 | **≤ 120 KB**（5 张合计 ≤600 KB） | 分类图是氛围图，不需要景点图的清晰度 |
| 构图要求 | 主体居中；**画面下部 1/3 保持简洁、无杂物** | 下 1/3 会被白色渐变盖住并压组名 |
| 内联 | base64 直接写进 `<img src>` | 同全篇铁律：单文件、不外链 |

### 五类各拍什么（**显式字典，不得现编**）

| 分组 | `{画面主体}` 写什么 |
|---|---|
| 🏛 **景点** | 目的地**标志性山水/地形的全景**（峰林江面、雪山天际线一类）—— 要一眼认得出是哪座城 |
| 🍜 **美食** | **本地招牌食物的桌面特写** ／ 街边小吃摊的烟火气（**二选一，全篇统一**，不要混） |
| 🏨 **住宿** | 民宿或客栈的**外观 / 庭院**（青瓦木门一类的地域形制），安静时段的光线 |
| 🚇 **交通** | 站台 / 码头 / 公路 —— **有移动感但没有人脸**（车流光轨、江面渡船、站台风） |
| 📸 **打卡** | 一处**取景位**看出去的画面（人少、有前景框）—— 读者看了就知道"站这儿拍" |

### 提示词

复用 §3 骨架，改三处：

1. **画幅段** → `wide panoramic crop, 4:1 horizontal, main subject centered, the lower third of the frame kept simple and uncluttered`
2. **保留**末行 `no illustration, no cartoon, no vector art, no flat geometric shapes`
3. **追加** `no text, no signage, no watermark`（分类图不承载文字——组名与渐淡都由 CSS 加）

> ⚠️ **不要在生图提示词里写"底部渐淡"** —— 生图端给不出可控的渐变。**渐淡是 CSS 的活**（模板 `.pfhead::after`），图只需要"下部干净"。

### 降级

| 档 | 触发条件 | 做法 |
|---|---|---|
| **L1 · AI 生成**（默认） | 环境有生图能力 | 按上表生成 → 裁压 → base64 内联 |
| **L0 · 无图**（保底） | 环境**没有**生图能力 | **整块删掉 `<div class="pfhead">`**，组名落到白底卡首行 |

**分类图不用 SVG 意象图保底。** 景点图的 SVG 是"这个具体景点的符号"，而分类图是**氛围图**——符号化之后就没有意义。**宁可不给，也不要一张错位的图。**

### 与景点图的分工

| | 景点图（§1–§8） | 分类图（本节） |
|---|---|---|
| 数量 | 每张景点卡 1 张 | 每个非空分组 1 张 |
| 回答的问题 | **这个景点长什么样** | **这一类长什么样** |
| 画幅 | 3:2 → 裁 2.5:1 横条 | 4:1 超宽横条 |
| 留白要求 | 主体居中 60%，上下留可裁区 | 主体居中 + **下部 1/3 干净** |
| 文字压在哪 | 图的**左下角**（主张标签） | 图的**下部渐淡区**（组名） |
| 单张体积 | ≤160 KB | ≤120 KB |
