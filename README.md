# travel-guide-once · 一次性旅行攻略生成器 - 作者：锌刻度

在Agent里说一句「帮我出一份 XX 旅行攻略」，这个 skill 就会先和你对一遍行程（天数 / 人数 / 预算 / 老人小孩约束），再端到端生成一份**单文件 HTML**：双击即开、图片全部内嵌、零外链，手机电脑都能看。

## 成品长什么样

单个 .html 文件，五大板块：

1. **封面** —— 该时节该景点的 AI 生图（中国风 × 胶片做旧）
2. **行程总览** —— 事实卡、安排思路、预算构成、出发前、天气行李
3. **景点** —— 必去 / 值得 / 可选 三档卡片，每张带实景图
4. **每日行程** —— 按天排的动线，内嵌腾讯地图路线图 + 真实店名餐饮节点
5. **行程全貌** —— 脑图 + 背诵口诀

## 文件结构

    SKILL.md                主工作流（Agent会先读它）
    assets/template.html    交付时套用的HTML模板文件
    references/             各子模块规范（封面/生图/地图/内容/文案/设计/核验）
    scripts/                生成脚本 + 示例输入

## 腾讯地图（可选增强）

不开也完全可用：攻略照出，每日动线用「文字 + 序号」表达，景点就近美食走公开信息核验。

配了Key后能拿到**更准确、可交互感更好的页面**（每日路线图 + 真实耗时 + 就近美食）。启用时Agent会引导你走几步网页配置：建应用→建 Key（勾选 WebServiceAPI）→ 在「配额管理」里一键分配额度 → 把Key给Agent。Key只存本地工作区，**不写进产物或提交到仓库**。

## 开发者

- scripts/check_consistency.py：交付前结构自检
- scripts/make_route_map.py：腾讯地图静态图内嵌（需 Key）
- scripts/strip_node_ids.py：剥除编辑痕迹属性
